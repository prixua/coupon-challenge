# Sistema de Cupons

Sistema de gerenciamento de cupons com desconto.

Utilizado arquitetura hexagonal para desacoplar lógica da aplicação da infra.

## Quick Start

```bash
docker compose down && docker compose up --build
```

A aplicação estará disponível em: **http://localhost:8080**

## Documentação da API

Acesse a documentação interativa do Swagger em: **http://localhost:8080/swagger-ui.html**
